Pω sets a fast real closed-loop pole at ≈Pω/Imin. A fixed integration step safe for the paper's default (Pω=4) is too coarse once you raise the slider — the loop would chatter, the same failure mode a too-slow digital control tick has on real hardware. The physics step is recomputed from Pω every frame instead; watch the HUD's CTRL / dt readout react as you drag.
